## 概要

`Apache ECharts` は高機能な可視化ライブラリで、分析ダッシュボード寄りの UI に強い。

参考:

- [Apache ECharts 公式](https://echarts.apache.org/)
- [React Wrapper 例](https://echartsforreact.com/)

## このプロジェクトとの相性

相性は悪くないが、MVP にはやや強すぎる。

理由:

- ズーム、ツールチップ、領域選択、複雑な設定などが非常に強い
- 将来的な分析画面には向く
- 一方で、今回必要な「シンプルな日次推移グラフ」だけならオーバースペックになりやすい

## 想定実装イメージ

```tsx
const option = {
  xAxis: { type: "category", data: dates },
  yAxis: { type: "value", min: 0, max: 5 },
  series: [
    { name: "physical", type: "line", data: physical },
    { name: "mental", type: "line", data: mental },
  ],
};

return <ReactECharts option={option} />;
```

## メリット

- 機能が非常に豊富
- 将来、ズームや分析系のインタラクションを足しやすい
- 高密度データや複雑な可視化にも対応しやすい
- オプションベースで細かい調整ができる

## 注意点

- 学習コストが高め
- React らしい JSX 合成より、設定オブジェクト中心の設計になる
- `shadcn/ui` との統合は見た目をこちらで丁寧に合わせる必要がある
- MVP の要件に対しては重い可能性がある

## このプロダクトでの向き不向き

向いている:

- 将来、分析画面を強化したい
- かなりリッチなチャート操作を入れたい
- グラフ機能をプロダクトの中心に据えたい

あまり向いていない:

- MVP のシンプルな時系列折れ線グラフ
- UI コンポーネント方針と自然に揃えたいケース

## 総評

将来の拡張を強く見据えるなら有力だが、現時点の要件にはやや過剰。

今の段階では、最初からこれを選ぶより、まずはより軽い候補で始める方が現実的。
