## 概要

`Nivo` は React 向けのチャートライブラリで、見栄えの良いチャートを比較的少ないコードで構築しやすい。

参考:

- [Nivo 公式](https://nivo.rocks/)
- [Line Chart](https://nivo.rocks/line/)

## このプロジェクトとの相性

相性は良いが、`Recharts + shadcn/ui` ほど自然ではない。

理由:

- グラフ自体の表現力は高い
- テーマ調整もしやすい
- ただし `shadcn/ui` との直接的な結びつきはない
- SSR では `ResponsiveLine` ではなくサイズ指定版を使うなどの注意が必要

## 想定実装イメージ

```tsx
<Line
  width={720}
  height={320}
  data={series}
  xScale={{ type: "point" }}
  yScale={{ type: "linear", min: 0, max: 5 }}
  axisBottom={{ legend: "日付" }}
  axisLeft={{ legend: "スコア" }}
/>
```

## メリット

- デフォルトでも見栄えが良い
- 折れ線以外のチャート種類も豊富
- SVG / Canvas 系の選択肢がある
- 将来的にダッシュボード感を強めたい場合に伸ばしやすい

## 注意点

- SSR 時は Responsive コンポーネントの扱いに注意が必要
- レイアウトやサイズ制御をやや丁寧に設計する必要がある
- `shadcn/ui` 前提のサンプル資産は少ない

## このプロダクトでの向き不向き

向いている:

- MVP 以降も複数のグラフを増やしたい
- ある程度デザイン性を重視したい
- Recharts より表現の幅を少し広げたい

あまり向いていない:

- とにかく最短で実装したい
- `shadcn/ui` と完全に同じ作法で組みたい

## 総評

`Recharts + shadcn/ui` の次点候補。

MVP だけなら少し重いが、今後グラフの種類を増やしたいなら十分有力。SSR の扱いだけ、最初に設計方針を決めておくと安心。
