## 前提

比較対象は、`US-7: 推移グラフ表示` を実現するためのライブラリ。

求める条件:

- 折れ線グラフを素直に実装できる
- React / TanStack Start と相性がよい
- `shadcn/ui` や Tailwind と併用しやすい
- MVP の 7日 / 14日 / 30日切替に対応しやすい
- 将来的にツールチップ、凡例、ズーム、系列追加にも伸ばせる

## 比較サマリー

| 候補 | 向いているケース | 強み | 注意点 | MVP 適性 |
| --- | --- | --- | --- | --- |
| [Recharts + shadcn/ui](/docs/research/charts/recharts-shadcn) | シンプルで見た目を整えやすい折れ線グラフ | 現在の UI 方針と最も整合的。実装コストが低い | 大規模で複雑な可視化には限界がある | ◎ |
| [Nivo](/docs/research/charts/nivo) | デザイン性を上げたい、将来グラフ種類を増やしたい | 見栄えが良く、チャートの種類も多い | SSR では Responsive 系に注意が必要 | ○ |
| [Apache ECharts](/docs/research/charts/echarts) | 高機能・高インタラクションを重視 | 機能が非常に豊富。ズームや分析系 UI が強い | 学習コストと重量感がある。MVP にはやや過剰 | △ |

## 比較観点

| 観点 | Recharts + shadcn/ui | Nivo | Apache ECharts |
| --- | --- | --- | --- |
| 導入しやすさ | 高い | 中程度 | 中程度 |
| UI との一体感 | 非常に高い | 高い | 中程度 |
| SSR との相性 | 比較的良い | 注意点あり | ラッパー選定が必要 |
| カスタマイズ性 | 中程度 | 高い | 非常に高い |
| 学習コスト | 低い | 中程度 | 高い |
| 将来拡張性 | 中程度 | 高い | 非常に高い |

## 選定結果

推移グラフ表示には `Recharts + shadcn/ui` を採用する。

理由:

- `shadcn/ui` の chart ドキュメントが Recharts ベースで、現在の UI 方針と自然につながる
- 折れ線グラフ、ツールチップ、凡例、期間切替の実装がわかりやすい
- 体力 / 気力の 2 系列グラフなら十分に対応できる
- デザイン調整を Tailwind と CSS 変数でまとめやすい

比較候補として調べた結果、以下の理由で今回は見送る:

- グラフの種類を多数増やしたい: `Nivo`
- ズーム、データ密度、分析ダッシュボード寄りの機能を重視: `Apache ECharts`

## 補足

将来的に可視化要件が大きく増えた場合は、再評価の余地がある。
