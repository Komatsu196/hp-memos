---

WebAuthn パスキーの認証情報を保管する。

## カラム定義

| カラム | 型 | 制約 | 説明 |
| --- | --- | --- | --- |
| `id` | `text` | PK | CUID2 で生成 |
| `user_id` | `text` | FK → `users.id`, NOT NULL | パスキー所有者 |
| `credential_id` | `text` | UNIQUE, NOT NULL | WebAuthn Credential ID（Base64URL） |
| `public_key` | `bytea` | NOT NULL | COSE 公開鍵 |
| `counter` | `bigint` | NOT NULL, DEFAULT `0` | 署名カウンタ（リプレイ攻撃防止） |
| `transports` | `text[]` | NULL | `'usb'`, `'ble'`, `'nfc'`, `'internal'` 等 |
| `device_type` | `text` | NULL | `'singleDevice'` / `'multiDevice'` |
| `backed_up` | `boolean` | NOT NULL, DEFAULT `false` | クラウドバックアップ状態 |
| `created_at` | `timestamptz` | NOT NULL, DEFAULT `now()` | 登録日時 |

## 外部キー

| カラム | 参照先 | ON DELETE |
| --- | --- | --- |
| `user_id` | `users.id` | CASCADE |

## インデックス

| 名前 | カラム | 用途 |
| --- | --- | --- |
| `idx_credentials_user_id` | `user_id` | ユーザーのパスキー一覧取得 |

## Drizzle スキーマ

```ts
import { pgTable, text, bigint, boolean, timestamp, index, customType } from "drizzle-orm/pg-core";
import { createId } from "@paralleldrive/cuid2";
import { users } from "./users";

const bytea = customType<{ data: Uint8Array }>({
  dataType() {
    return "bytea";
  },
});

export const credentials = pgTable(
  "credentials",
  {
    id: text("id")
      .primaryKey()
      .$defaultFn(() => createId()),
    userId: text("user_id")
      .notNull()
      .references(() => users.id, { onDelete: "cascade" }),
    credentialId: text("credential_id").notNull().unique(),
    publicKey: bytea("public_key").notNull(),
    counter: bigint("counter", { mode: "number" }).notNull().default(0),
    transports: text("transports").array(),
    deviceType: text("device_type"),
    backedUp: boolean("backed_up").notNull().default(false),
    createdAt: timestamp("created_at", { withTimezone: true })
      .notNull()
      .defaultNow(),
  },
  (table) => [
    index("idx_credentials_user_id").on(table.userId),
  ],
);
```
