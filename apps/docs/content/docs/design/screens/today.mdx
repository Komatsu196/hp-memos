ルート `/`。認証必須。アプリの主動線であり、毎日の記録はこの画面だけで完結する。

対応: US-4（コンディション記録）、US-5（一言コメント）、US-10（朝・夜の区別）、US-11（回復量）、US-12（消耗量）、US-7（推移グラフ・直近 7 日）

## レイアウト

上から順に配置する。入力欄が常にファーストビューに収まることを最優先とし、320px でスクロールなしに保存ボタンまで到達できること。

| 順 | 要素 | 内容 |
| --- | --- | --- |
| 1 | ヘッダー | `今日 9/5（金）` と記録状況（`夜がまだです` など） |
| 2 | 朝／夜タブ | `TimeOfDayTabs`。選択中のタイミングを切り替える |
| 3 | 記録カード | `RecordCard`。体力バー・気力バー・コメント・保存ボタン |
| 4 | 推移グラフ | `TrendChart`。直近 7 日、期間切替なし |
| 5 | 下部タブ | 今日 / 履歴 / 設定 |

朝と夜を縦に並べず、タブで排他的に切り替える。片方だけを表示することで、入力欄をスクロールなしの位置に固定する。

## 朝／夜タブ

| 項目 | 仕様 |
| --- | --- |
| 選択肢 | 朝（`morning`） / 夜（`evening`）の 2 つ |
| 初期選択 | 12:00 以前は朝、12:00 以降は夜（US-10 の自動判定） |
| ラベル | 記録済みなら記録時刻、未記録なら `未記録` を併記する |
| 切り替え | 常に手動で切り替え可能。自動判定が外れた場合の逃げ道になる |

タブの切り替えは表示の切り替えのみで、未保存の入力値は破棄せず保持する。

## 記録カード

`RecordCard` は朝・夜どちらか 1 件ぶんを担当する。

| 要素 | 仕様 |
| --- | --- |
| 体力バー | `ConditionBar`。0〜5 の 0.5 刻み、11 段 |
| 気力バー | `ConditionBar`。同上 |
| 差分 | 各バーの値の右に `DeltaLabel`。起点と符号付き数値 |
| 点線マーカー | 起点の値の位置にバー上に重ねる。ラベルに起点の実値（`朝 3.5`）を出す |
| コメント | 任意、最大 200 文字。朝・夜それぞれが独立して持つ |
| 保存 | 未記録なら `POST /api/records`、記録済みなら `PATCH /api/records/:id` |

### 差分の起点

| 表示中のタブ | 起点 | 表記 | 対応 |
| --- | --- | --- | --- |
| 朝 | 前日夜の記録 | `前夜から +1.5` | US-11 回復量 |
| 夜 | 同日朝の記録 | `朝から −2.0` | US-12 消耗量 |

起点となる記録が存在しない場合、点線マーカー・起点ラベル・数値をまとめて表示しない。

差分は保存後だけでなく **入力中もリアルタイムに更新する**。バーを動かしながら起点との距離が縮む・伸びるのが見えることで、数値を読まずに「朝より下げすぎたか」を把握できる。

## 状態

| 状態 | 表示 |
| --- | --- |
| 当該タイミングが未記録 | バーは中央（2.5）を初期値とし、保存ボタンは `保存` |
| 当該タイミングが記録済み | 保存済みの値を表示。変更すると保存ボタンが活性化し、`更新` に変わる |
| 反対側のタイミングも未記録 | 差分は表示しない |
| 記録が 1 件もない（初回） | 通常どおり入力欄を表示する。グラフ領域は「まだ記録がありません」 |

## 推移グラフ

直近 7 日を固定で表示する。期間切替は履歴画面に置き、この画面では持たない。

| 項目 | 仕様 |
| --- | --- |
| 種別 | 折れ線（Recharts。[グラフ表示ライブラリ比較](/docs/research/charts)） |
| 系列 | 体力・気力の 2 系列 |
| X 軸 | 記録点（1 日あたり最大 2 点。朝・夜） |
| Y 軸 | 0〜5 |
| 欠損日 | 線を切る。未記録と低スコアを混同させない |

## 使用 API

| 目的 | エンドポイント |
| --- | --- |
| 当日の記録取得 | `GET /api/records?from=<today>&to=<today>` |
| 前日夜の記録取得（回復量用） | `GET /api/records?from=<yesterday>&to=<yesterday>` |
| グラフ用データ | `GET /api/records?from=<today-6>&to=<today>&limit=100` |
| 新規保存 | `POST /api/records` |
| 更新 | `PATCH /api/records/:id` |

グラフ用のクエリが直近 7 日を含むため、当日ぶんと前日ぶんは同じレスポンスから取り出せる。実装時は 1 リクエストにまとめる。

## エラー

| 条件 | 挙動 |
| --- | --- |
| `CONFLICT`（同日・同タイミングに既存） | 画面を開いてから他端末で記録された場合に起きる。既存の記録を読み直し、更新（`PATCH`）に切り替えて再試行を促す |
| `VALIDATION_ERROR` | 該当バーの直下にメッセージを表示 |
| 通信失敗 | トーストで再試行を促す。入力値は保持する |
