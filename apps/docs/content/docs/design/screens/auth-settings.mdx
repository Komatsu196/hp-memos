認証系 2 画面と設定画面。いずれも定型的な構成で、独自の設計判断は含まない。

対応: US-1（アカウント登録）、US-2（ログイン・パスワード）、US-3（ログイン・パスキー）、US-9（ログアウト）

## ログイン（`/login`）

認証不要。認証済みでアクセスした場合は `/` にリダイレクトする。

| 要素 | 仕様 |
| --- | --- |
| ユーザーID | 英数字・アンダースコア、4〜32 文字 |
| パスワード | 8 文字以上 |
| ログインボタン | `POST /api/auth/login` |
| パスキーでログイン | WebAuthn 認証（`POST /api/auth/webauthn/login/options` → `verify`） |
| 登録への導線 | `/register` へのリンク |

| 状況 | 表示 |
| --- | --- |
| 認証失敗 | 「ユーザーID またはパスワードが違います」。どちらが誤りかは示さない |
| 試行回数超過 | ロック中である旨と解除までの目安を表示（5 回失敗で一時ロック） |
| パスキー非対応ブラウザ | パスキーのボタンを表示しない。パスワード認証にフォールバックする |

成功後は `/`（今日）に遷移する。

## アカウント登録（`/register`）

認証不要。

| 要素 | 仕様 |
| --- | --- |
| ユーザーID | 英数字・アンダースコア、4〜32 文字 |
| パスワード | 8 文字以上、英大文字・小文字・数字・記号を含む |
| 登録ボタン | `POST /api/auth/register` |

| 項目 | 仕様 |
| --- | --- |
| バリデーション | 入力中に要件の充足状況を表示する。サーバー側でも全項目を検証する |
| ID 重複 | `CONFLICT` を受けてユーザーID 欄にメッセージを表示 |
| 完了後 | ログイン状態になり `/` に遷移する。パスキー登録は促さず、設定画面に任せる |

## 設定（`/settings`）

認証必須。下部タブの 1 つ。

| セクション | 内容 |
| --- | --- |
| アカウント | ユーザーID の表示（変更は MVP スコープ外） |
| パスキー | 登録済みパスキーの一覧、追加、削除 |
| セッション | ログアウト |

### パスキー

| 操作 | API |
| --- | --- |
| 登録 | `POST /api/auth/webauthn/register/options` → `POST /api/auth/webauthn/register/verify` |
| 一覧 | 登録済み認証器を作成日時とともに表示 |
| 削除 | 確認ダイアログを挟む |

パスキー非対応ブラウザではセクションごと非表示にし、対応環境が必要である旨を示す。

### ログアウト

`POST /api/auth/logout` を呼び、セッション破棄後に `/login` にリダイレクトする（US-9）。確認ダイアログは挟まない。
