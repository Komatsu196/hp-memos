[画面設計](/docs/design/screens) で定義した画面を構成するコンポーネントの方針。

## 原則

| 原則 | 内容 |
| --- | --- |
| 単一の目的 | 1 コンポーネント 1 責務。内部を読まずに用途が分かる名前と props にする |
| 状態を持ち上げない | 入力部品は値を受け取り変更を通知するのみ。保存やフェッチの責務を持たせない |
| 画面をまたいで共有する | 同じ意味を持つ表示は同じコンポーネントで描く。今日と `/records/$date` は入力部を共有する |
| アクセシビリティ | キーボードのみで主要機能を操作できること。バーには `aria-label` と `aria-valuemin` / `aria-valuemax` / `aria-valuenow` を付与する（[非機能要件](/docs/requirements/non-functional)） |

## レイヤー

| レイヤー | 役割 | 例 |
| --- | --- | --- |
| Primitives | shadcn/ui 由来の低レベル UI。ドメイン知識を持たない | Button、Card、Dialog、Tabs、Toast |
| Domain | 体力・気力という語彙を知っている表示部品 | `ConditionBar`、`DeltaLabel`、`TrendChart` |
| Features | 特定画面の 1 ブロック。ローカルな入力状態を持ち、確定した値を親に渡す | `RecordCard`、`RecordList` |

Domain 層は API・ルーティングに依存しない。値と表示指定だけを受け取り、テストが単体で完結すること。

データ取得と保存はルートコンポーネントが担い、Features 層には結果とコールバックだけを渡す。どのレイヤーのコンポーネントも自身で `fetch` しない。

## 主要コンポーネント

### `ConditionBar`

体力・気力の入力部品。11 段の目盛りバー。

| props | 型 | 説明 |
| --- | --- | --- |
| `value` | `number` | 0〜5、0.5 刻み |
| `onChange` | `(v: number) => void` | 変更通知 |
| `baseline` | `number \| undefined` | 起点の値。指定時は点線マーカーを重ねる |
| `baselineLabel` | `string \| undefined` | マーカーのラベル（`朝 3.5`） |
| `variant` | `"physical" \| "mental"` | 色の切り替え |
| `aria-label` | `string` | 読み上げ用（`体力` / `気力`） |

| 挙動 | 仕様 |
| --- | --- |
| 入力 | タップ・ドラッグの両方。押した位置の段にスナップする |
| キーボード | 左右矢印で 0.5 ずつ、Home / End で 0 / 5 |
| 段の高さ | 左から右へ段階的に上げ、値を読まずに段数を把握できるようにする |
| タッチ | バー全体を操作領域とし、高さ 44px 以上を確保する |

### `DeltaLabel`

差分を起点付きで表示する。

| props | 型 | 説明 |
| --- | --- | --- |
| `delta` | `number` | 符号付きの差 |
| `origin` | `string` | 起点の呼称（`朝` / `前夜`） |

`前夜から +1.5` のように、起点・助詞・符号付き数値の順で描く。`delta` を渡さない場合は何も描かない（起点となる記録がない場合）。

### `RecordCard`

朝または夜 1 件ぶんの入力・表示。今日（`/`）と `/records/$date` で共有する。

| props | 型 | 説明 |
| --- | --- | --- |
| `record` | `Record \| null` | 既存の記録。`null` なら新規 |
| `baseline` | `Record \| null` | 差分の起点となる記録 |
| `originLabel` | `string` | 起点の呼称 |
| `onSave` | `(input) => Promise<void>` | 保存 |

体力バー・気力バー・コメント（200 字）・保存ボタンを含む。差分は入力中もリアルタイムに再計算する。

### `TimeOfDayTabs`

朝／夜の切り替え。各タブに記録済みかどうかを併記する。切り替えは表示のみを変え、未保存の入力値は保持する。

### `TrendChart`

体力・気力の推移を描く折れ線（Recharts）。

| props | 型 | 説明 |
| --- | --- | --- |
| `records` | `Record[]` | 記録点の配列 |
| `range` | `7 \| 14 \| 30` | 期間（日数） |

| 仕様 | 内容 |
| --- | --- |
| 系列 | 体力・気力の 2 系列 |
| X 軸 | 記録点（1 日あたり最大 2 点） |
| Y 軸 | 0〜5 固定 |
| 欠損日 | 線を切る |

### `RecordListItem` / `EmptyDayRow`

履歴一覧の 1 行。前者は記録のある日（`体力 3.5 → 1.5` の矢印形式）、後者は未記録日（破線枠と `＋ 記録する`）を描く。いずれもタップで `/records/$date` に遷移する。

## 命名・配置

- ディレクトリ規則は [ファイル命名](/docs/rules/file-naming) を参照する。
- Primitives は `src/components/ui/`（shadcn/ui の既定）、Domain と Features は機能単位のディレクトリに置く。
- 共有 UI パッケージ `packages/ui` は現状どのアプリからも import されていない。本設計のコンポーネントは `apps/web` 内に置き、複数アプリで必要になった時点で移動を検討する。
