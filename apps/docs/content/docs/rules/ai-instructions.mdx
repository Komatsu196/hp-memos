## 作業前に読む順序

1. [用語集](/docs/overview/glossary)
2. このページ（禁止事項・スコープ）
3. 関連する [ADR](/docs/decisions/001-monorepo-tool)

## 作業テンプレート（依頼側）

- **目的**: （何を達成するか）
- **スコープ**: 変更してよいパス / 触ってはいけない領域
- **完了条件**: （テスト・ビルド・レビュー観点）
- **参照**: 関連 Issue・PR・ドキュメント

## 禁止事項（例）

- 依頼されていない大規模リファクタや無関係ファイルの編集
- 秘密情報・認証情報のコミット
- ユーザー向けドキュメントの未確認な断定

## 出力の期待

- 変更理由を短く説明できること
- 既存のコードスタイル・命名に合わせること
