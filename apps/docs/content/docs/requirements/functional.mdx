## ユーザーストーリー

テンプレート:

> **As a** （役割）
> **I want** （やりたいこと）
> **So that** （得たい価値）

---

## MVP v1

### US-1: アカウント登録

> **As a** 新規ユーザー
> **I want** ユーザーID とパスワードでアカウントを作成したい
> **So that** 自分専用の記録環境を持てる

#### 受け入れ条件

- Given: 未登録のユーザーがアカウント登録画面を開いたとき
- When: ユーザーID（英数字）とパスワードを入力して送信する
- Then: アカウントが作成され、ログイン状態になる

| 項目 | 仕様 |
| --- | --- |
| ユーザーID | 英数字・アンダースコア、4〜32文字 |
| パスワード | 8文字以上、英大小文字・数字・記号を含む |

---

### US-2: ログイン（パスワード）

> **As a** 登録済みユーザー
> **I want** ユーザーID とパスワードでログインしたい
> **So that** 自分の記録にアクセスできる

#### 受け入れ条件

- Given: ログイン画面を開いたとき
- When: 正しいユーザーID とパスワードを入力する
- Then: ダッシュボード（一覧画面）にリダイレクトされる

- Given: ログイン画面を開いたとき
- When: 誤ったパスワードを入力する
- Then: エラーメッセージが表示され、ログインできない

---

### US-3: ログイン（パスキー）

> **As a** 登録済みユーザー
> **I want** パスキー（生体認証・セキュリティキー）でログインしたい
> **So that** パスワード入力なしで素早く安全にログインできる

#### 受け入れ条件

- Given: パスキーが未登録のとき
- When: 設定画面からパスキー登録を実行する
- Then: ブラウザの WebAuthn API が起動し、パスキーが紐付けられる

- Given: パスキーが登録済みのとき
- When: ログイン画面でパスキー認証を選択する
- Then: 生体認証 or セキュリティキーで認証が完了し、ダッシュボードに遷移する

---

### US-4: コンディション記録

> **As a** ユーザー
> **I want** 今日の体力と気力をスライダーで記録したい
> **So that** 自分の状態を数値として残せる

#### 受け入れ条件

- Given: ログイン済みのユーザーが記録画面を開いたとき
- When: 体力（0〜5）と気力（0〜5）をスライダーで設定し、保存する
- Then: 今日の日付で記録が保存される

| 項目 | 仕様 |
| --- | --- |
| 体力（フィジカル） | 0〜5（スライダー、0.5 刻み・11 段階） |
| 気力（メンタル） | 0〜5（スライダー、0.5 刻み・11 段階） |
| 日付 | 自動で当日日付を付与（手動変更は不可） |

---

### US-5: 一言コメント記録

> **As a** ユーザー
> **I want** コンディション記録に一言コメントを添えたい
> **So that** 数値だけでは表現できない気持ちや状況を残せる

#### 受け入れ条件

- Given: 記録画面でコンディションを入力しているとき
- When: コメント欄にテキストを入力して保存する
- Then: コンディション記録とともにコメントが保存される

| 項目 | 仕様 |
| --- | --- |
| コメント | 任意入力、最大 200 文字 |

---

### US-6: 記録一覧表示

> **As a** ユーザー
> **I want** 過去の記録を日付順に一覧で確認したい
> **So that** 自分のコンディション履歴を振り返れる

#### 受け入れ条件

- Given: ログイン済みのユーザーがダッシュボードを開いたとき
- When: 一覧画面を表示する
- Then: 記録が日付の新しい順に表示される

| 項目 | 仕様 |
| --- | --- |
| 表示項目 | 日付・体力・気力・コメント（抜粋） |
| ソート | 日付降順（新しい順） |
| ページング | 無限スクロール or ページネーション |

---

### US-7: 推移グラフ表示

> **As a** ユーザー
> **I want** 体力と気力の推移をグラフで確認したい
> **So that** 自分の状態変化を視覚的に把握できる

#### 受け入れ条件

- Given: ログイン済みのユーザーがグラフ画面を開いたとき
- When: グラフが表示される
- Then: 体力と気力が折れ線グラフで時系列表示される

| 項目 | 仕様 |
| --- | --- |
| グラフ種別 | 折れ線グラフ |
| 系列 | 体力（フィジカル）、気力（メンタル） |
| X 軸 | 日付 |
| Y 軸 | 0〜5 |
| デフォルト期間 | 直近 7 日間 |
| 期間切替 | 7日 / 14日 / 30日 |

---

### US-8: 記録の編集

> **As a** ユーザー
> **I want** 過去の記録を編集したい
> **So that** 入力ミスを修正できる

#### 受け入れ条件

- Given: 一覧画面で過去の記録を選択したとき
- When: 体力・気力・コメントを変更して保存する
- Then: 記録が更新される

---

### US-9: ログアウト

> **As a** ユーザー
> **I want** ログアウトしたい
> **So that** 共用端末で安全に利用を終了できる

#### 受け入れ条件

- Given: ログイン済みの状態で
- When: ログアウト操作を実行する
- Then: セッションが破棄され、ログイン画面にリダイレクトされる

---

## MVP v2

### US-10: 朝・夜の記録区別

> **As a** ユーザー
> **I want** 朝と夜でそれぞれコンディションを記録したい
> **So that** 1日の中での変化を把握できる

#### 受け入れ条件

- Given: 記録画面を開いたとき
- When: 「朝」または「夜」を選択して記録する
- Then: 同じ日付に朝・夜それぞれの記録が保存される

| 項目 | 仕様 |
| --- | --- |
| 記録タイミング | 朝（morning） / 夜（evening） |
| 1日の上限 | 朝1回・夜1回（計2回） |
| デフォルト選択 | 12:00 以前 → 朝、12:00 以降 → 夜（自動判定） |

---

### US-11: 回復量の表示

> **As a** ユーザー
> **I want** 前日の夜と今日の朝の差分を「回復量」として確認したい
> **So that** 回復できているかを実感できる

#### 受け入れ条件

- Given: 朝の記録を保存したとき
- When: 前日の夜の記録が存在する場合
- Then: 体力・気力それぞれの回復量（差分）が表示される

| 項目 | 仕様 |
| --- | --- |
| 回復量 | 今朝の値 − 前日夜の値 |
| 表示形式 | +1.5 / -0.5 のように符号付き |
| データ不足時 | 前日夜の記録がない場合は「—」と表示 |

---

### US-12: 1日の消耗量の表示

> **As a** ユーザー
> **I want** 朝と夜の差分を「消耗量」として確認したい
> **So that** 1日の負荷を把握できる

#### 受け入れ条件

- Given: 夜の記録を保存したとき
- When: 同日の朝の記録が存在する場合
- Then: 体力・気力それぞれの消耗量（差分）が表示される

| 項目 | 仕様 |
| --- | --- |
| 消耗量 | 夜の値 − 朝の値 |
| 表示形式 | +0.5 / -2.0 のように符号付き |
| データ不足時 | 朝の記録がない場合は「—」と表示 |

---

### US-13: グラフの朝夜対応

> **As a** ユーザー
> **I want** グラフで朝・夜の両方のデータポイントを確認したい
> **So that** 1日の中での変動パターンも可視化できる

#### 受け入れ条件

- Given: グラフ画面を開いたとき
- When: 朝夜の記録データが存在する場合
- Then: 1日に2つのデータポイント（朝・夜）が表示される
