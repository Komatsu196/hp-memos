## 性能

| 指標 | 目標 | 備考 |
| --- | --- | --- |
| ページ初期表示 | 3 秒以内 | LCP（Largest Contentful Paint） |
| API レスポンス p95 | 500ms 以内 | 記録保存・取得 |
| グラフ描画 | 1 秒以内 | 30日分のデータポイント |
| Lighthouse Performance | 80 以上 | モバイル基準 |

## 可用性・信頼性

| 項目 | 方針 |
| --- | --- |
| 稼働率目標 | 99%（月間ダウンタイム約 7 時間まで許容） |
| データバックアップ | DB プロバイダ（Supabase / Neon）の自動バックアップに依存 |
| 障害時の対応 | 個人プロジェクトのため、手動復旧 |
| データ喪失リスク | マネージド DB を利用し、ポイントインタイムリカバリを有効化 |

## セキュリティ

### 認証

| 項目 | 方針 |
| --- | --- |
| 認証方式 | ユーザーID / パスワード + パスキー（WebAuthn） |
| パスワード保存 | bcrypt or Argon2 によるハッシュ化 |
| セッション管理 | サーバーサイドセッション or JWT（有効期限付き） |
| パスキー | WebAuthn Level 2 準拠、discoverable credentials 対応 |
| ブルートフォース対策 | ログイン試行回数制限（5回失敗で一時ロック） |

### データ保護

| 項目 | 方針 |
| --- | --- |
| 通信暗号化 | HTTPS 必須（TLS 1.2 以上） |
| データアクセス制御 | ユーザーは自分の記録のみ参照・更新可能 |
| 入力値バリデーション | サーバーサイドで全入力を検証 |
| XSS 対策 | フレームワークのエスケープ機能 + CSP ヘッダ |
| CSRF 対策 | SameSite Cookie + CSRF トークン |

### 依存関係

| 項目 | 方針 |
| --- | --- |
| pnpm パッケージ | 定期的に `pnpm audit` を実行 |
| 脆弱性対応 | Critical / High は 1 週間以内に対応 |

## レスポンシブ対応

| 項目 | 仕様 |
| --- | --- |
| ブレークポイント | モバイル（〜768px）/ デスクトップ（769px〜） |
| モバイルファースト | スマホ表示を基本とし、デスクトップで拡張 |
| タッチ操作 | スライダーはタッチ操作に最適化 |
| 最小対応幅 | 320px |

## アクセシビリティ

| 項目 | 目標 |
| --- | --- |
| 基準 | WCAG 2.1 Level AA（可能な範囲で準拠） |
| キーボード操作 | 主要機能はキーボードのみで操作可能 |
| コントラスト比 | 4.5:1 以上（通常テキスト） |
| スライダー | aria-label、aria-valuemin/max/now を付与 |

## 運用・監視

| 項目 | 方針 |
| --- | --- |
| エラー監視 | Vercel のビルトインログ（初期） |
| アプリケーションログ | API エラー・認証失敗をログ出力 |
| パフォーマンス監視 | Vercel Analytics（初期） |
| アラート | 個人プロジェクトのため、初期は手動確認 |
