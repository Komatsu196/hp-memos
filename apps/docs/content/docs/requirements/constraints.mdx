## ビジネス上の制約

| 項目 | 内容 |
| --- | --- |
| 開発体制 | 個人開発（1人） |
| 予算 | 無料枠中心（Vercel Free / Supabase Free or Neon Free） |
| MVP v1 期限 | 1〜2 週間 |
| MVP v2 期限 | MVP v1 完了後 +1〜2 週間 |
| 収益化 | 当面なし（個人利用が目的） |

## 技術的制約

### フロントエンド

| 項目 | 制約 |
| --- | --- |
| 言語 | TypeScript（strict モード必須） |
| フレームワーク | TanStack Start |
| 対応ブラウザ | Chrome / Safari / Firefox（最新2バージョン） |
| モバイルブラウザ | iOS Safari / Android Chrome |
| JavaScript | 必須（NoScript 環境は非対応） |

### バックエンド

| 項目 | 制約 |
| --- | --- |
| 言語 | TypeScript（strict モード必須） |
| API フレームワーク | Hono（TanStack Start にマウント） |
| ランタイム | Node.js（Vercel Serverless Functions） |
| コールドスタート | サーバーレス特有のコールドスタートを許容 |

### データベース

| 項目 | 制約 |
| --- | --- |
| DBMS | PostgreSQL |
| ホスティング | Supabase or Neon（Free Tier） |
| 接続数制限 | Free Tier の接続プール上限に依存 |
| ストレージ | Free Tier の容量上限に依存（500MB 程度） |

### インフラ

| 項目 | 制約 |
| --- | --- |
| ホスティング | Vercel（Free Plan） |
| リージョン | Vercel / DB ともに同一リージョン推奨 |
| カスタムドメイン | 初期は Vercel 提供の URL を使用 |
| CI/CD | Vercel の Git 連携による自動デプロイ |

### 認証

| 項目 | 制約 |
| --- | --- |
| パスキー | WebAuthn 対応ブラウザが必要 |
| パスキー非対応時 | ユーザーID / パスワード認証にフォールバック |
| 外部認証プロバイダ | 使用しない（自前実装 or ライブラリ） |

## 前提条件

| 項目 | 内容 |
| --- | --- |
| 言語 | TypeScript で統一（`any` 禁止、strict モード有効） |
| モノレポ構成 | Turborepo によるモノレポ管理 |
| パッケージ管理 | pnpm |
| 環境セットアップ | mise（Node.js・pnpm 等のバージョン管理） |
| AI 支援 | Cursor を開発ツールとして使用 |
| ユーザー数 | 初期は 1 人（自分のみ） |
| データ量 | 1日最大2件 × 365日 = 年間約730件（十分に少量） |
| ネットワーク | オンライン前提（オフライン対応は MVP スコープ外） |

## スコープ外（MVP v1・v2 では対応しない）

- AI によるフィードバック機能（MVP v3 で検討）
- タスク管理機能
- 感情タグ機能
- ソーシャル機能（他ユーザーとの共有）
- データエクスポート / インポート
- PWA / オフライン対応
- ネイティブアプリ
- 多言語対応（日本語のみ）
