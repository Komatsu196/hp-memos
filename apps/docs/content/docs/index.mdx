## プロジェクト概要

このリポジトリ（hp-memos）の目的・スコープ・関係者向けの入口です。詳細は [概要](/docs/overview/concept) や各章を参照してください。

| 章 | 内容 |

| [Overview](/docs/overview/concept) | コンセプト・用語・ロードマップ |
| [Requirements](/docs/requirements/functional) | 機能・非機能要件と制約 |

| [Decisions](/docs/decisions/001-monorepo-tool) | ADR（アーキテクチャ決定記録） |

**AI エージェント**は特に [Rules](/docs/rules/ai-instructions) と [Glossary](/docs/overview/glossary) を先に確認してください。
